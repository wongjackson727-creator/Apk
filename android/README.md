# Android App：Duo 庫存監測

Android Studio 專案，可安裝在 Android 8.0（API 26）或更新版本。App 以系統 JobScheduler 每小時在背景查詢 Apple 中國大陸門店的取貨狀態，發現由無貨轉為有貨時送出本機通知。支援一次立即查詢、編輯 SKU 清單與監測門店。

## 建置與安裝

1. 安裝 Android Studio（含 Android SDK 35）。
2. Android Studio 選 **Open**，開啟本 `android/` 資料夾，等待 Gradle Sync。
3. 連接 Android 手機並啟用 USB 偵錯，按 **Run**；或從 Build 選單建置 APK。
4. 首次開啟允許通知。
5. 在商品欄逐行輸入每個要監測的容量／顏色 SKU：`Apple 型號代碼CH/A | Duo 容量／顏色`。
6. 門店欄預設載入附帶的 48 店清單，可編輯。按「儲存設定並啟用監測」。

## 背景行為

- 背景查詢間隔固定為 1 小時。Android JobScheduler 會配合省電、網路與系統負載安排執行，實際到達時間可能延遲。
- 「立即查詢一次」會交由 Android 系統安排一次網路工作。
- 通知只在該 SKU／門店由無貨轉有貨時送出。查詢錯誤會保留先前狀態，避免暫時性失敗觸發錯誤通知。
- 「停止背景監測」會取消週期工作。
- 型號代碼、門店與設定只保存在手機本機；沒有外傳設定或登入資料。

## 資料來源與限制

App 查詢 Apple 中國大陸官網的門店取貨介面。這不是 Apple 對外承諾穩定的公開開發者 API，Apple 可能調整介面或存取限制。隨 App 附帶的 48 家門店名單是 2025-10-06 的資料快照，首次使用前請核對 Apple 官方門店清單。Apple 顯示有貨不代表會為使用者保留商品，請立刻到 Apple 官方網站確認下單。
